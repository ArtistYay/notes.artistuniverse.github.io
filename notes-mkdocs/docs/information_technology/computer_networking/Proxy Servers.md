- A proxy is a type of gateway that sits between a private network and a public one. It usually needs application support and gets configured in the OS, a web browser, or another app.

- It's mostly for outbound traffic (a forward proxy). A reverse proxy is the opposite and sits in front of servers to handle inbound traffic.

- It can act as a filter or a web cache, which speeds up web access for a big organization at a remote site.

- Proxy servers can decide whether to pass traffic along based on things network layer appliances can't see, like a username or corporate identity.
