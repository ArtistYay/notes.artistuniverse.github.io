- You can create and use VMs in the cloud.

- It provides IaaS.

- Scale sets let you centrally manage, configure, and update a large number of VMs in minutes for highly available apps. It's like AWS Auto Scaling groups, but not exactly the same.

- Azure Batch enables large-scale parallel and high-performance computing (HPC) batch jobs with the ability to scale to tens, hundreds, or thousands of VMs.
